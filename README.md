# 我們的回憶小屋

給 11 月 11 日、21 歲生日的像素互動回憶錄。

## 預覽

在此資料夾執行 `python3 -m http.server 8000 --bind 127.0.0.1`，開啟 http://127.0.0.1:8000。

## 操作

- WASD 或方向鍵移動，E 互動。手機可使用畫面上的方向鍵。
- 點相框開啟相簿，可左右滑動或使用左右箭頭。
- 編輯作品可新增、替換、排序照片與修改文字；修改保存在目前瀏覽器的 IndexedDB。
- 匯出備份保存修改，其他裝置可匯入；不會自動同步至 GitHub 或網站。

## 檔案

- `index.html`：頁面與生日信。
- `style.css`：外觀。
- `app.js`：房間、角色、相簿互動。
- `editor.js`：瀏覽器內的編輯與備份。
- `memories.json`：照片順序與分組（日期不顯示於相簿）。
- `photos/`、`thumbs/`：照片與縮圖。

這個作品包含私人照片，請保留為私人儲存庫。
